# Security and privacy reports

Do not post Jellyfin tokens, API keys, private library exports or server addresses in public issues. For a sensitive issue, use GitHub private vulnerability reporting if enabled by the repository owner. Otherwise contact the owner through a private channel they publish, before disclosing details publicly.

This browser script runs with the permissions of the Jellyfin page. Review updates before installing. Prefer a tested release tag or commit for CDN installation. External requests omit credentials; authenticated library requests remain on your Jellyfin server.

There is no promised support window or audited security certification. Report the affected release, installation method, browser and minimal redacted reproduction.
